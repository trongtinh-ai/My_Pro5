CÁCH CHỈNH (mở bằng double-click index.html, không cần server)
Muốn đổi gì thì sửa đúng file đó trong thư mục data/:
  data/profile.js   tên, handle, role, bio, quote, ID Discord, múi giờ
  data/links.js     menu, mạng xã hội, các hàng link, Quick Links
  data/projects.js  dự án nổi bật
  data/setup.js     gaming setup & gears
  data/gallery.js   ảnh gallery
  data/contact.js   email / liên hệ
  data/site.js      ảnh nền (cả video), bố cục trái/phải, ẩn/hiện khối, màu sắc
  assets/           ảnh thật (thay file cùng tên, thêm cv.pdf cho nút Download CV)
Không cần đụng index.html, css/style.css, js/main.js.
Ảnh trong assets hiện chỉ là placeholder gradient.
